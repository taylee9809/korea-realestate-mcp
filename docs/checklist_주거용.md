# 주거용 건축물 위험 체크리스트

공인중개사법 시행규칙 별지 제20호서식 "중개대상물 확인·설명서[Ⅰ] (주거용 건축물)"을
기준으로 만든 체크리스트. 이 서식은 개업공인중개사가 법적으로 반드시 작성해야 하는
최소 확인의무 항목이라, "기본은 하는 중개사" 수준을 알고리즘으로 보장하는 게 목표.

각 항목에 [자동]이면 이 MCP의 기존 도구로 채울 수 있는 항목, [수동]이면 사용자가
직접 확인하거나 등기부등본처럼 유료 API가 필요한 항목.

법적 근거: 공인중개사법 시행규칙 제16조, 별지 제20호서식 (2024.7.2 개정 기준 —
재확인 필요 시 `search_law("공인중개사법 시행규칙")`로 최신본 조회할 것)

## Ⅰ. 개업공인중개사 기본 확인사항

### ① 대상물건의 표시
- [자동] 소재지, 면적, 용도(건축물대장상) — `get_building_title_info`
- [수동] 위반건축물 여부 — 2026-08-07 재확인: `get_building_title_info`(건축HUB 표제부) 응답에 필드 자체가 없음.
  건축법 제79조④는 "허가권자가 시정명령 시 건축물대장에 위반내용을 적어야 한다"고만 규정할 뿐,
  이를 공개 API 필드로 노출하는 근거는 없음 — 별도 하위서비스가 새로 생기기 전까진 구조적으로
  자동화 불가. (기존 [자동] 표기가 오기였음 — 정정)
- [수동] 실제 이용 상태(공부상 지목과 다를 수 있음), 방향, 내진설계 적용여부

### ② 권리관계 (등기부 기재사항)
- [수동] 소유권에 관한 사항, 소유권 외의 권리사항(근저당·전세권 등) — 등기부등본 필요, 건당 유료 (CODEF 등 3자 API)
- [수동] 신탁등기 여부, 공동담보 여부 — 등기부등본 확인 시 같이 봐야 함
- ⚠️ 시행규칙 작성방법에 명시된 실제 처벌 사례: "다세대주택 건물 전체 근저당권을 확인·제시하지 않고 일부 호실 채권최고액만 보여주는 것은 공인중개사법 위반으로 형사처벌 대상"

### ③ 토지이용계획, 공법상 이용제한 및 거래규제 (토지)
- [자동] 투기지역·투기과열지구·토지거래허가구역 지정 여부 — `search_law(target="admrul")`로 고시 검색
- [자동] 용도지역/용도지구/용도구역 지정 현황 — `get_land_use_zoning` (2026-08-06 브이월드로 구현·검증 완료,
  이전엔 [수동]이었으나 반영 안 된 채 남아있던 표기였음 — 정정)
- [수동] 건폐율·용적률 실제 상한, 지구단위계획구역 세부내용 — 국토계획법 제77조③·제78조③이 이 값을
  "시·군 조례"로 위임해서 전국 단일 API가 없음(구조적 한계, 단순 미구현이 아님). `korean-land-mcp`
  (GitHub, MIT)가 42개 법령 레이어를 이미 다루니 이식하면 확장 가능 — 별도 통합 작업으로 분리

### ④ 임대차 확인사항
- [자동] 전세가율 — `calc_jeonse_ratio` (매매가는 `get_apt_trade_price` 등, 전세가는 `get_apt_rent_price` 등)
- [자동] 최우선변제금 기준 — `search_law("주택임대차보호법 시행령")`로 소액임차인범위/최우선변제금액 확인
- [자동] 임대인 정보제시요청 문안 — `generate_landlord_disclosure_request` (확정일자 현황, 국세·지방세 완납증명)
- [자동] 전입세대확인서 신청 안내문·준비서류 — `generate_resident_registration_request`
  (단, 실제 열람·교부 자체는 주민등록법 제29조의2②가 신청권자를 본인/위임자로 제한해서
  API 대리조회가 법적으로 불가 — 안내만 자동화, 열람은 여전히 [수동])
- [수동] 전입세대확인서 실제 열람 결과, 계약갱신요구권 행사여부, 민간임대 등록여부

### ⑤ 입지조건
- [수동] 도로 접함 여부, 대중교통 접근성, 주차장, 교육시설까지 거리 — 지도 기반, QGIS 플러그인 연동 예정

### ⑥ 관리에 관한 사항
- [수동] 관리비, 관리주체 — 공개 데이터 없음, 관리사무소/임대인 확인 필요

### ⑦ 비선호시설(1km 이내)
- [수동] 화장장·봉안당·쓰레기처리장 등 — 별도 공간정보 API 필요 (미구현)

### ⑧ 거래예정금액 등
- [수동] 개별공시지가, 건물(주택) 공시가격 — data.go.kr에 API(데이터셋 3050651)는 존재하나
  2026-08-07 기준 서비스키 발급 후 Swagger 확인이 안 된 상태라 미구현(다음 우선순위)
- [수동] 거래예정금액 — 당사자 협의사항

### ⑨ 취득 시 부담할 조세의 종류 및 세율
- [자동] `calc_transfer_tax` (양도세)
- [자동] `calc_acquisition_tax` (취득세+지방교육세+농어촌특별세) — 2026-08-07 추가.
  calc_transfer_tax와 동일하게 세율표는 하드코딩하지 않고 호출자가 `search_law("지방세법")`로
  제11조(표준세율)·제13조의2(중과)·제14조(조례 가감)를 확인해서 넘기는 구조

## Ⅱ. 개업공인중개사 세부 확인사항 (전부 [수동] — 현장 확인 필요)
- ⑩ 실제 권리관계 또는 공시되지 않은 물건의 권리사항 (법정지상권, 유치권 등)
- ⑪ 내부·외부 시설물 상태 (수도·전기·가스·소방·난방·승강기·배수)
- ⑫ 벽면·바닥면 및 도배 상태 (균열·누수)
- ⑬ 환경조건 (일조량·소음·진동)
- ⑭ 현장안내자

## Ⅲ. 중개보수 등
- ⑮ 중개보수 및 실비 — 직거래(중개사 없음) 시 해당 없음
